# 料理分量らくらく計算（CookScale）

レシピの人数・分量を、料理中に使いやすい形へ変換する無料・登録不要のブラウザ完結Webツールです。

## コンセプト

「レシピの計算をする」のではなく、**料理中に発生する面倒な計算・換算を、その場で簡単に片付ける**ことを目的とします。

主な対象は、レシピの人数変更、分量倍率変更、計量単位の変換、計量しやすい表示への整形です。

## 主な特徴

- 無料・登録不要
- ブラウザだけで利用可能
- レシピを複数行まとめて貼り付け可能
- 元の人数から作る人数へ自動換算
- g / ml / 大さじ / 小さじ / カップを簡易認識
- 大さじ・小さじを料理で計量しやすい形へ整形
- 「少々」「適量」など、数値化しない表現はそのまま保持
- スマートフォンでの料理中利用を想定
- TypeScriptによる静的Webアプリ

## 使い方

1. レシピの材料を複数行まとめて貼り付けます。
2. 元の人数と作りたい人数を入力します。
3. 分量を自動計算します。
4. 計量しやすい表示で結果を確認します。

入力例：

```text
鶏もも肉 300g
醤油 大さじ2
みりん 大さじ1
砂糖 小さじ2
酒 大さじ1
塩 少々
```

## 今回の設計方針

CookScaleは、機能数を増やすことよりも、**料理中に迷わず使えること**を優先します。

特に以下を重視します。

- 入力をできるだけ簡単にする
- 計算結果を小数のまま表示しない
- 実際の計量に使いやすい表現を優先する
- 数値化できない表現を無理に変換しない
- 説明や操作を増やしすぎない

## 技術構成

- TypeScript
- Vite
- HTML / CSS
- ブラウザ完結の静的Webアプリ

## プライバシー

基本的な計算処理はブラウザ上で行い、レシピ入力内容を外部サービスへ送信することを前提としません。

## 対応範囲について

単位や食材によっては、単純な数式だけでは正確な換算ができない場合があります。
そのため、対応できないものを無理に変換せず、元の表現を保持することを基本方針とします。
