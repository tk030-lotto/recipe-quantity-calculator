# 料理分量らくらく計算（CookScale）
レシピの人数・分量を、料理中に使いやすい形へ変換するブラウザ完結Webツールです。

## こんなときに
- 4人分のレシピを2人分（または3人分）に作り直したいとき
- 大さじ・小さじの計量計算や、g・ml・カップなどの人数倍率計算を手間なく済ませたいとき
- 料理中に電卓を使わず、レシピのテキストをまとめて換算したいとき

## 主な機能
- レシピテキストの一括貼り付け・解析（改行・読点・カンマ・スペース区切り対応）
- 人数変更に伴う分量の自動再計算
- 大さじ・小さじの扱いやすい組み合わせ表示（例: 大さじ1＋小さじ1.5）
- カップの分数表示（1/4、1/3、1/2、2/3、3/4）および分数・帯分数入力（1/2、1と1/2、½ など）への対応
- 「少々」「適量」などの非数値表現の自動保持
- 換算できない行（範囲指定など）の元表記維持と注意表示
- 計算結果のワンクリック一括コピー
- よく使うレシピのお気に入り保存（お使いのブラウザ内、最大10件）
- ダークモード表示切り替え（システム設定への自動追従対応）

## 使い方

### ブラウザで使う（かんたん）
1. [料理分量らくらく計算を開く](https://zero-dev.jp/recipe-quantity-calculator/) をクリックします。
2. 「元の人数」と「作りたい人数」を入力します。
3. 「レシピ（材料と分量）を入力」の欄に、材料と分量を貼り付けます。
4. 画面下部に、換算された分量が自動で表示されます。
5. 必要なら、「結果をコピー」を押すと、クリップボードにコピーできます。

> リポジトリをダウンロードして使う場合は、`ツール起動.bat`（Windows・Python が必要）でローカルサーバーを起動するか、上の公開 URL を使ってください。`index.html` を直接開くと、`file://` では module の読み込みが遮断され、白い画面になります。

## うまくいかないとき
- 分量が計算されないとき: 「鶏肉 300g」のように、材料名と分量が判別できる形式で入力されているか確認してください。
- 保存したお気に入りが消えたとき: ブラウザの履歴やサイトデータを削除すると、保存されたデータも消去されます。

## 動作環境
- モダンブラウザ（Google Chrome, Apple Safari, Mozilla Firefox, Microsoft Edge の最新版）
- スマートフォン・タブレット・PC対応

## 制限・注意
- 単位そのものの変換（カップからgやmlへの換算など）は行いません。各単位のまま人数倍率を計算します。
- 範囲表記（例: `100〜150g`）や材料名のない数値のみの行は、誤換算を防ぐため換算せず元の表記のまま表示します。
- 丸め仕様: カップは一般的な分数（1/4, 1/3, 1/2, 2/3, 3/4）に近い場合は分数で、それ以外は小数第2位で表示します。kg・Lは小数第2位、g・ml・個数などは小数第1位で丸めて表示します。
- **お気に入りに保存したレシピだけ**が、お使いの端末（ブラウザの localStorage）に保存されます（最大10件）。入力中のレシピ・人数は保存されないため、再読み込みやタブを閉じると消えます。

## 外部通信
外部への通信は行いません。すべての処理はお使いのブラウザ内で完結します。
