# 料理分量らくらく計算（CookScale）
レシピの人数・分量を、料理中に使いやすい形へ変換するブラウザ完結Webツールです。

## こんなときに
- 4人分のレシピを2人分（または3人分）に作り直したいとき
- 大さじ・小さじの計量計算や、カップ・gの換算を手間なく済ませたいとき
- 料理中に電卓を使わず、レシピのテキストをまとめて換算したいとき

## 主な機能
- レシピテキストの一括貼り付け・解析
- 人数変更に伴う分量の自動再計算
- 大さじ・小さじの扱いやすい組み合わせ表示（例: 大さじ1＋小さじ1.5）
- 「少々」「適量」などの非数値表現の自動保持
- 計算結果のワンクリック一括コピー
- よく使うレシピのお気に入り保存（お使いのブラウザ内）
- ダークモード表示切り替え

## 使い方

### ブラウザで使う（かんたん）
1. [料理分量らくらく計算を開く](https://zero-dev.jp/recipe-quantity-calculator/) をクリックします。
2. 「元の人数」と「作りたい人数」を入力します。
3. 「レシピの材料を貼り付け」の欄に、材料と分量を貼り付けます。
4. 画面下部に、換算された分量が自動で表示されます。
5. 必要なら、「結果をコピー」を押すと、クリップボードにコピーできます。

## うまくいかないとき
- 分量が計算されないとき: 「鶏肉 300g」のように、材料名と数値の間にスペースが入っているか確認してください。
- 保存したお気に入りが消えたとき: ブラウザの履歴やキャッシュを削除すると、保存されたデータも消去されます。

## 動作環境
- モダンブラウザ（Google Chrome, Apple Safari, Mozilla Firefox, Microsoft Edge の最新版）
- スマートフォン・タブレット・PC対応

## 制限・注意
- 複雑な分数表記（帯分数など）や、特殊な単位には対応していない場合があります。
- 入力データやお気に入りは、お使いの端末（ブラウザの localStorage）にのみ保存されます。

## 外部通信
外部への通信は行いません。すべての処理はお使いのブラウザ内で完結します。
